# Design: 共享策略包下发（policy-distribution）

## Context

现有护栏规则在 kongming 本地；访问策略分散；没有统一策略包版本/回滚。规则体属于服务域配置，不能上收。

## Goals / Non-Goals

**Goals:**
- 共享策略包激活/作用域/版本单一来源。
- 服务可 last-known 执行。

**Non-Goals:**
- 不做策略 DSL 引擎。
- 不拥有服务域规则体/规则类型。
- 不做实时策略推送。

## Decisions

1. 锦官只存策略包引用、作用域、激活状态与版本；规则体/规则类型在服务 admin API。
2. 快照按服务投影；服务在自己的规则目录中解析包引用；缺失/非法 fail-closed。
3. 策略包内容不含密钥/凭据。
4. 激活/回滚显式确认并审计；锦官只读展示服务规则页，规则写入只在服务管理台。

## Risks / Trade-offs

- 策略包误激活影响全量 → 确认/审计/回滚。
- 包引用与服务规则目录漂移 → 契约测试/服务注册能力目录。
- 快照体积 → 按服务投影、压缩。

## Migration Plan

greenfield 新增表；kongming 删除共享策略编辑，保留本地规则目录；服务侧后续接入。

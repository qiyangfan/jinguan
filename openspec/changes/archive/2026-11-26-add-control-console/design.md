# Design: 锦官控制台 + 服务只读视图（control-console）

## Context

现有 jinguan web 只有钱包/支付/价目/拓扑/绑定；共享控制新域尚无页面。服务域配置已有本地管理 API，但缺少统一只读视图。

## Goals / Non-Goals

**Goals:**
- 共享控制数据可读写。
- 服务域配置可经服务只读 API 展示，形成统一入口。
- 服务宕机时共享控制仍可用。

**Non-Goals:**
- 不直连服务 DB。
- 不复制服务域配置/凭据/运行时数据。
- 不做运行时诊断替代服务本地台。

## Decisions

1. 沿用 jinguan web，按共享控制域分组；服务域配置按服务分组，标注“只读”。
2. 共享控制写操作要求原因/确认/审计；命令显示 pending。
3. 服务域配置页调用服务只读 API；锦官不落库、不缓存敏感值；写只在服务管理台。
4. 服务不可用时：共享控制页正常；服务域配置页显示不可用/stale。
5. 人类登录跳符节/Keycloak；锦官只做 RP，不做 SSO。

## Risks / Trade-offs

- 页面增多 → 分组/懒加载。
- 只读视图与服务只读 API 漂移 → 契约测试/生成客户端。
- 误操作 → 确认/审计/回滚；服务端最终裁决。

## Migration Plan

无数据迁移；新增前端路由与服务只读 API 客户端。

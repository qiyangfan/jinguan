# 设计:持久化密钥 fail-fast

## 结论

用显式部署开关 `require-persistent-keys` 控制:true 时缺目录即拒启;false 保留开发
临时密钥。不在代码里猜环境,也不让生产依赖告警。

## 备选比较

| 方案 | 结论 | 理由 |
| --- | --- | --- |
| 保持告警 + 临时密钥 | 否决 | 生产漏配的代价是重启全员掉线,告警不够 |
| 一律要求密钥目录 | 否决 | 本地开发/单测需先造密钥,违背即时起步 |
| 显式开关 fail-fast | 采纳 | 生产部署显式声明;开发零成本;行为可测试 |

## 失败模式

- 开关 true + 目录空:启动抛 `IllegalStateException`,日志明确缺配置项。
- 开关 true + 目录存在但 `active.pem` 缺失/不可读:沿用现有加载错误拒启。
- 开关 false:与原行为一致(告警 + 临时密钥)。

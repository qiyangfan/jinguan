# 设计：标识与一次性凭据明确分开

绑定对象是与计量 APIKeyID 相同的源端记录 ID。界面显示“密钥标识（Key ID）”，帮助文本点名木牛密钥列表、签发结果和 `keys list` 入口；明文密钥只用于调用鉴权，不作为绑定字段。

ID 是不透明字符串，不转换大小写、重建 ID 或用 prefix/key 兜底；仅拒绝空白输入。保留现有管理员权限、目标用户校验和请求字段。平台自定义标识包括 k-1，既有测试还有 mk-test-1；不得加 UUID 正则或 mk- 前缀拒绝规则。

不增加源端实时查询或共享浏览器凭据。木牛同名提案在既有列表和签发结果提供真实 ID；当前 CLI/API 已能取得 ID，因此此件无需等待新后端发卡能力。

回归验证应使用本地签发 ID 与平台自定义 ID 两类样本，实际产生用量后检查绑定命中与本人明细。错误输入不写日志中的明文秘密；页面不把凭据缓存到 localStorage。

相关依据：key-lifecycle 主规格、控制面契约登记与钱包归账边界。收款继续 Mock，字段形态与既有到期/吊销契约保持。
